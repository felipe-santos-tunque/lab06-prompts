# Tarea: Mi prompt profesional
 
## Funcionalidad elegida
 Un programa para registrar el estado (préstamo, en stock, sin stock) y la entrada y salida de libros de una biblioteca nacional. 
## Version 1: prompt basico
 ```bash
 Crea un programa en java para gestionar los libros de una biblioteca
 ```
## Version 2
 ```bash
 Adopta el rol de programador senior. Crea un programa en java para gestionar los libros de una biblioteca
 ```

 Agregue el rol para poder ver la diferencia entre lo que me entregaba el prompt anterior. Aunque fue más técnico no ofrecio mucha mejora en cuanto al prompt anterior
## Version 3: prompt final
  ```bash
Adopta el rol de programador senior. Crea un programa en java para gestionar los libros de una biblioteca. Agrega la clase usuario, que contenga nombre, codigo. Utiliza la nomenclatura camel para los metodos por ejemplo getUsuario(), setNombre(). Explica primero las clases, sus metodos, y despues brinda el codigo.
 ```
 Inclui la clase y las normas para nombrar los métodos. 

## Componentes del prompt final
 | Componente | Texto de mi prompt |
|------------|:--------------------:|
| Rol |Adopta el rol de programador senior |
| Instruccion | Agrega la clase usuario, que contenga nombre, codigo.|
| Contexto |Crea un programa en java para gestionar los libros de una biblioteca |
| Ejemplo |Utiliza la nomenclatura camel para los metodos por ejemplo getUsuario(), setNombre() |
| Formato | Explica primero las clases, sus metodos, y despues brinda el codigo.|

## Evaluacion del resultado

| Criterio | Prompt básico | Prompt V 2 |Prompt Final|
|----------|:-------------:|:-----------------:|:--:|
| Menciona el objetivo del sistema |Sí|Sí|Sí|
| Explica detalladamente los métodos |No|No|Sí|
| Propone mejoras |No |Sí |Sí|
| Ejemplifica el funcionamiento del programa |Sí|Sí|Sí|

## Errores que evite
La falta de contexto: al indicarla explícitamente la finalidad del programa. 
No indicar el formato: detalle la estructura en la cual quería que se me brindase la respuesta.
